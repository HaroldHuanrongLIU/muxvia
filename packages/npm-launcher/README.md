# Muxvia npm launcher

This package selects the exact-version Muxvia platform package for the current machine, verifies its complete Release Bundle, and starts the bundled `muxvia` executable. It never downloads executables during installation and never modifies the installed package tree.

See the repository's [release documentation](https://github.com/HaroldHuanrongLIU/muxvia/blob/main/docs/releases.md) for supported platforms and repair instructions.
