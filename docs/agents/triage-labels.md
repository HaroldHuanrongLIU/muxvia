# Triage labels

The engineering skills speak in terms of five canonical triage roles. This repository uses the default label string for each role.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is required from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or coordination. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill names a role, use the corresponding GitHub label in this table.
