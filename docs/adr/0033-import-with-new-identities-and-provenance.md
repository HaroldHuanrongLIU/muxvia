# Import with new identities and provenance

Every imported Provider receives a new Muxvia UUID and Import Provenance; migration never overwrites an existing record or reuses a source identity. Equal names may coexist with their origins shown, while an exact normalized configuration match is offered for merge only in the migration preview. Provider Presets and one-time seeds use stable preset keys rather than Provider IDs or names. Historical CC-Switch usage is a separate, default-off migration option that previews its count, date range, and estimated size.
